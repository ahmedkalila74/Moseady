مساعدي 3.3.1 — تعليمات الرفع والتنظيف

مهم: هذه الحزمة تحتوي ملفات المصدر الجديدة كاملة، وليست APK. لا تحذف شيئًا يدويًا قبل نجاح البناء.

1) فك ضغط Mosaedy_3_3_1_ALL_FLAT_UPLOAD.zip في الهاتف.
2) افتح مستودع ahmedkalila74/Mosaedy على فرع main في GitHub.
3) من Code اختر Add file ثم Upload files.
4) ارفع إلى جذر المستودع كل الملفات التي تبدأ بـ M3__ ومعها M3_MANIFEST.json. لا ترفع مجلدًا فرعيًا ولا ترفع ZIP نفسه.
5) اضغط Commit changes وانتظر تشغيل Actions. قد يظهر تشغيل من Workflow قديم أيضًا؛ ركّز على Build Mosaedy Android APK (Clean 3.1).
6) إذا انتهى تشغيل Clean 3.1 باللون الأخضر، افتح نفس Workflow واضغط Run workflow مرة واحدة على main.
7) هذا التشغيل ينشئ Tag احتياطيًا، يبني APK، ثم يستبدل الملفات المسطحة بمجلدات المشروع النظيفة. لا تشغّل خطوة التنظيف إذا فشل البناء.
8) نزّل Artifact من تشغيل Run workflow الناجح. اسم Workflow قديم، لكن الإصدار داخل التطبيق 3.3.1.
9) بعد نجاح التنظيف، اترك Workflow التنظيف وحده نشطًا. احذف أي Workflow بناء قديم زائد فقط بعد التأكد أن Workflow التنظيف ما زال موجودًا ويعمل.
10) قبل تحديث التطبيق على الهاتف، صدّر نسخة احتياطية من الإعدادات. إذا رفض Android التحديث بسبب اختلاف توقيع Debug، احذف النسخة القديمة فقط بعد النسخ الاحتياطي ثم ثبّت الجديدة واستعد النسخة.

الميزات الموجودة في هذا الإصدار: واجهة Mosaedy البنفسجية، زرا الصوت واليدوي في الرئيسية، مراجعة قبل الحفظ، تاريخ ووقت منفصلان بعجلة، 12 ساعة افتراضيًا و24 ساعة اختياريًا، العربية والإنجليزية، فهم المدد النسبية والتاريخ، حفظ النص الأصلي وعنوان مختصر، ألارم برنين مستمر افتراضيًا أو إشعار، مدد تأجيل قابلة للتخصيص، اختيار نغمة، مركز المواعيد والسجل والتكرار، النسخ الاحتياطي، وجلسة نداء تجريبية محدودة بخمس دقائق.

حدود مهمة: جلسة النداء ليست استماعًا دائمًا. Android قد يمنع فتح التطبيق تلقائيًا من الخلفية أو أثناء قفل الشاشة؛ عندها يظهر إشعار يضغط عليه المستخدم بعد فتح الهاتف.

إذا فشل البناء: لا تشغّل التنظيف. أرسل أول خطوة حمراء وأول سطر error: مع 20 سطرًا حوله.
