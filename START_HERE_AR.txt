مساعدي 3.1 — تحديث ترفعه مرة واحدة

1) قبل أي تحديث للـAPK، افتح مساعدي القديم > الإعدادات > تصدير نسخة احتياطية من المواعيد.
2) فك ضغط هذا ZIP في مجلد على الهاتف. ستجد كل الملفات على مستوى واحد؛ لا توجد فولدرات فرعية.
3) افتح https://github.com/ahmedkalila74/Moseady في Chrome على فرع main.
4) من الصفحة الرئيسية للمشروع (Code) اختر Add file > Upload files، وحدّد جميع الملفات الموجودة هنا وارفعها معًا، ثم Commit changes.
5) لا تحذف .github/workflows ولا ترفع ZIP نفسه. عملية GitHub الحالية يجب أن تحتوي setup-android@v4 كما عدلناها سابقًا.
6) اذهب إلى Actions > Build Mosaedy Android APK، وافتح أحدث عملية أو شغّل Run workflow إن لم تبدأ تلقائيًا.
7) عند نجاح البناء نزّل Artifacts ثم ملف APK داخل ZIP.
8) إذا رفض الهاتف التثبيت فوق النسخة القديمة بسبب اختلاف توقيع Debug: احتفظ بالنسخة الاحتياطية أولاً، ثم احذف القديم وثبّت الجديد واستورد المواعيد.

مهم: حتى لو Build نجح، الصوت والتذكيرات تحتاج اختبار فعلي. لا يوجد استماع تلقائي لكلمة يا مساعدي وهو مقفول في هذه النسخة.
